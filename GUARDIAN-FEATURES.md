# CCS Lab Guardian

Redesigned from the original PTF50-MCO project.

## Added
- CCS Lab Guardian dashboard UI
- People/object/alert statistics
- COCO-SSD confidence display
- Persistent watched-object tracking
- Unattended-item timer
- 30-second live unattended warning
- Recent activity/alert history
- Live lab status
- Upload Photo and Live Webcam modes
- AI assistance disclaimer
- Responsive pastel UI

## Important
The app still uses the original COCO-SSD pre-trained model. It does not claim to identify ownership of objects.
